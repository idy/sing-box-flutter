Choose the constructors
Pick endpoints, outbounds, DNS, TLS and services. The builder resolves required dependencies; shared implementations can still contribute bytes.
One Go engine on iOS
The Packet Tunnel extension owns the core. The main app uses Swift preflight and control, without linking another Go engine.
Keep each app’s build separate
Fingerprinted artifacts stay in your app’s .dart_tool. Gradle and CocoaPods reject stale or modified cores.

From selection
to connection.

Build the core on your development machine.
The installed app needs no separate Go installation.

  1. Add the plugin. Pick a profile.

    Add this source dependency and your chosen sing_box_flutter.core block to the host app’s pubspec. The three profiles above use the repository’s actual YAML files.

    The 0.3.0 package is in preparation. This pinned source revision already supports selectable builds. See published versions.

    pubspec.yaml
    dependencies:
  sing_box_flutter:
    git:
      url: https://github.com/idy/sing-box-flutter.git
      ref: 860152060fdfe954871ac579dcb483123dae81a4

# Add the feature selection shown above
# as a separate top-level block.
    flutter pub get

  2. Compile your native core.

    Run the build command from your app. It downloads and verifies the pinned Tailscale Go compiler and produces the native SDK for your selection.

    Rebuild after changing the pubspec or native inputs. Ordinary Flutter builds do not compile Go automatically.

    dart run sing_box_flutter build --target android

    Python 3.11+, Git, JDK 17, Android SDK and NDK 28.0.13004108. Flutter packaging also uses NDK 28.2.13676358.

  3. Connect through the Flutter API.

    Build your app against the generated core. Configure your host’s VPN integration, request permission, then start with your sing-box JSON.

    On iOS, create and sign a Packet Tunnel extension with a matching App Group. App-side preflight checks structure and capabilities; full native validation runs before connecting.

    iOS host setup
    Dart · iOS initialization shown
    final vpn = SingBoxFlutter();
await vpn.initialize(
  appGroup: 'group.com.example.app',
  providerBundleIdentifier:
      'com.example.app.PacketTunnel',
);
await vpn.checkConfig(configJson);
if (await vpn.requestPermission()) {
  await vpn.start(config: configJson);
}

    Observe vpn.status for the connection outcome. Omit the App Group and provider options on Android.
